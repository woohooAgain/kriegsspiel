# Task decomposition (backlog/FS-* → волны и T-*)

Полный шаблон: `docs/projectDocs/templates/taskDecompositionTemplate.md`. Правила здесь — обязательный минимум для `architect`.

## Вход
- Цель/контекст.
- Утверждённая `FS-*` (`ready_for_decomposition`) и/или зафиксированные решения по неоднозначностям, или `N/A` с причиной.
- Требования: `rules.md §…`, трассы K/B/D, backlog.
- Текущая база кода (refs), ограничения, критерии приёмки эпика.
- Техдолг: `docs/projectDocs/tech-debt.md` — учесть `open`/`planned` или явно зафиксировать «не включать» с причиной.

## Правила
- **File ownership строго:** у каждой задачи `Владеет файлами` (включая `(новый)` и строку `Не трогать другие файлы.`). Исполнитель не трогает чужие файлы.
- **Независимость внутри волны:** задачи не пересекаются по файлам и параллельны в группах launch-плана.
- **Волны/зависимости:** `Wave N`, поле `Зависимости`; интеграция — в следующих волнах.
- **Launch-план для orchestrator:** машиночитаемая/явная часть — параллельные группы `T-*` без пересечений ownership, порядок, зависимости, refs на сценарий/gate.
- **Сценарий проверок волны (обязательно):** общие проверки + проверки добавленных/изменённых механик; если их нет — явно «достаточно сборки и запуска». Граница — перечисление; при неясности — эскалация.
- **Проверяемость:** у каждой `T-*` — воспроизводимые `Как проверить` и проверяемые `Готово, если` (3–8 пунктов). Gate `verifier` решает достаточность; при недостаточности ветка волны не создаётся.
- **Трассировка:** `Покрывает` → `§…`/`FS-*`/K/B/D; не придумывать несуществующие ID.
- **Корректирующие задачи:** маппинг «причина/затронутые T-* → корректирующая T-*» с обоснованной разбивкой (разные причины — разные задачи; одна причина с пересекающимся ownership — одна задача; падение автотестов — по умолчанию одна задача на инцидент/причину).
- Канонические команды: `dotnet build Kriegsspiel.slnx`, `dotnet test Kriegsspiel.Core.Tests/Kriegsspiel.Core.Tests.csproj` (или `dotnet test Kriegsspiel.slnx`).
- Код без комментариев, если не просили. `AGENTS.md`/`rules.md` не менять без запроса.

## Формат карточки
```md
### T-XX — <краткое имя>
- **ID:** `T-XX`
- **Волна:** Wave N
- **Покрывает:** <FS-* / §... / K/B/D>
- **Владеет файлами:**
  - `путь/к/файлу`
  - `путь/к/новому` (новый)
  - Не трогать другие файлы.
- **Зависимости:** <нет | T-* | Wave N>
- **Что сделать:**
  1. ...
- **Как проверить:**
  - `<команда/шаг>`
  - Утверждения: <ожидаемое поведение>
- **Готово, если:**
  - [ ] ...
```
