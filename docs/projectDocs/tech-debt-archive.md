# Архив технического долга

## Правила
- Записи сохраняют исходный идентификатор `TD-###` (не переиспользовать).
- Формат записи совместим с `tech-debt.md` (статус, даты, контекст, источник, описание, риск, действия, связи, сведения о закрытии).
- Архив используется для трассируемости; новые находки добавляются в активный `tech-debt.md`.
