# Промпт: приём находки в техдолг (любая роль)

Роль: любая (`implementer`, `verifier`, `scenario-tester`, `rules-auditor`, `planner`).

## Когда использовать
Найдена проблема/риск **вне текущей задачи**, которую нельзя или нецелесообразно править сейчас.

## Что сделать
1. Проверить, нет ли уже похожей записи в `docs/projectDocs/tech-debt.md`.
2. Подготовить запись по шаблону файла `tech-debt.md`: `TD-###` (следующий свободный номер), статус `open`, дата, контекст (`T-*`/прогон), источник (файлы/символы), описание, риск, предлагаемые действия, связи (`docs/gameDocs/rules.md §…`, `T-*`).
3. Если находка связана с планом — указать, в какой волне/карточке логичнее закрыть.

## Выход
Готовый блок markdown для вставки в `docs/projectDocs/tech-debt.md` (или список предложений, если править файл сейчас нельзя).
