## Что сделано
- `MapRenderer`: масштабируемое топологическое представление графа знаний вместо единственной большой таблицы. Компактный обзор (сводка по состояниям знания, конфликтам, типам рёбер и узлам по связям; страницы по 12 зон; 6 колонок с метками события/доставки, уверенностью и обеими версиями при противоречии), деталь зоны (знание §6, все версии/источники/метки, соседи с типом ребра и временем перехода, свои в зоне, противник только по знанию), сводка подразделений (группировка своих по зонам + поиск, занятость только из `PlayerKnowledge`). Публичные `BuildPage`/`BuildDetail`/`BuildUnitSummary`/`BuildSummary` дают воспроизводимую проверку без терминала; `Render(GameState)` сохранён.
- `MapCommand`: подменю карты — `ДЕТАЛЬ ЗОНЫ` (выбор со страницы или ввод ID/названия, resolve нескольких совпадений), `СОСЕДИ`, `К ОБЗОРУ`, `ФИЛЬТР` (состояние/сторона по донесениям/не опознана/только противоречия), `ПОИСК`, `ПОДРАЗДЕЛЕНИЯ`, `ДАЛЬШЕ`, `НАЗАД ПО СТРАНИЦАМ`, `СБРОС`, `ВЫХОД`. Пустые строки ввода допустимы (`AllowEmpty`).
- Разделение источников явно подписано в UI: статическая топология, знание по донесениям, данные управления своими силами. Enemy-юниты из `state.Units` не отображаются; `PresentUnitIds` не используется. Комментарии в коде не добавлены.
