# Handoff-артефакты (file-first)

Каталог для структурированных handoff-вводов между ролями (в первую очередь `implementer` → `verifier`, при необходимости `scenario-tester`/др.), чтобы детали передавались через артефакты, а не через inline-текст в оркестрацию.

## Правила
- Именование: `implementer-T-XX-r<N>.md` (раунд `N`), либо `<role>-<target>-r<N>.md` по договорённости процесса.
- Файлы могут коммититься в ветке задачи/волны, если это требуется для доступности и трассируемости; не заменяют канонические `task-*`/`wave-*` отчёты (владелец — `verifier`).
- В коммуникации с `orchestrator` передавать только **Status Envelope + ref** на файл; полные логи/копипасты запрещены. На доработках — дельта (новый раунд/обновление с пометкой изменений).
- Устаревшие handoff-файлы можно удалять/заменять по решению в рамках ветки, если канонический отчёт и refs сохраняют нужную трассируемость.
