# Локальный черновик handoff (опционально)

Каталог для **локальных gitignored черновиков** (scratch) при подготовке handoff/проверок. Не является обязательным транспортом и не должен быть единственным источником данных для `verifier`.

- Предпочтительный file-first handoff для процесса: `docs/projectDocs/reports/handoffs/implementer-T-XX-r<N>.md` (или иной согласованный артефакт в ветке/репозитории) + Status Envelope с refs.
- Содержимое `.tmp/*` (кроме этого файла) игнорируется git; не полагаться на него для межролевой передачи.
- Долгоживущие временные файлы не накапливать.
