# Технический долг (operational backlog находок)

Этот файл фиксирует **находки вне текущей задачи**, которые могут “выстрелить позже” (риски, расхождения, латки, архитектурные компромиссы). Он **отдельно** от:
- `docs/projectDocs/todo.md` — утверждённые исполняемые задачи/карточки `T-*` (план waves);
- `docs/gameDocs/featureBacklog.md` — игровые идеи и механики (не обязательно уже согласованные в плане).

## Как использовать
- Планировщик/декомпозитор обязан **читать этот файл перед декомпозицией** беклога или новой волны.
- Находки добавляются **по факту** (из разработки, ревью, проверки соответствия правилам, интеграционного прогона). Не превращать сюда срочные правки, если их можно и нужно сделать в текущей задаче по согласованию.
- Любая запись должна быть проверяемой/конкретной: ссылки на файлы, символы, разделы `rules.md` (`§…`), связанные `T-*`.

## Правила
- Формат записи: стабильный идентификатор **`TD-###`** (по возрастанию, не переиспользовать).
- Для каждой записи указывать: дату фиксации, контекст (какая задача/поток: `T-*`, “декомпозиция …”, “ручной прогон …”), источник (пути/символы/команды).
- Не менять `AGENTS.md` и `docs/gameDocs/rules.md` из-за задач техдолга без отдельного запроса.
- Закрытие: ставить статус `done` и ссылку на `T-*`/PR/коммит-текст в описании, если применимо; `wontfix` только с явной причиной.

## Статусы
- `open` — зафиксировано, не запланировано.
- `planned` — включено в `todo.md` (указать `T-*` или ссылку на пункт).
- `done` — устранено.
- `wontfix` — осознанно не делаем (причина обязательна).

## Шаблон записи
```md
## TD-001 — Краткое название
- **Статус:** open | planned | done | wontfix
- **Дата:** YYYY-MM-DD
- **Контекст:** T-XX / декомпозиция / прогон сценария / …
- **Источник:** `путь/к/файлу`, символ/секция, команда/наблюдение
- **Описание:** что обнаружено (факты)
- **Риск / почему может выстрелить:** …
- **Предлагаемые действия:** …
- **Связи:** `docs/gameDocs/rules.md §…`, `T-*`, `docs/projectDocs/…`
- **Примечание:** (ссылки на коммиты/решения; для `wontfix` — причина)
```
