# Бизнес-спецификации фич (`FS-*`)

Каталог содержит бизнес-спецификации/описания фич, которые готовит `analyst` на основе `docs/gameDocs/featureBacklog.md` и связанных запросов. Спеки — вход для `architect` при декомпозиции в `T-*` и волны (`docs/projectDocs/templates/taskDecompositionTemplate.md`).

## Правила
- `FS-*` не заменяет `todo.md` (утверждённые задачи/волны) и не является каноническими правилами игры (`docs/gameDocs/rules.md`).
- Спека доводится до состояния **готово к декомпозиции**: цель и поведение понятны, scope/non-scope определены, неоднозначности разрешены или эскалированы (канон `rules.md` меняется только отдельным запросом), есть проверяемые критерии готовности.
- Именование: `FS-<id>-<kebab-slug>.md` (id стабилен в рамках спеки).

## Шаблон
```md
# FS-<id> — <название>

- **Статус:** draft | in_review | ready_for_decomposition | blocked
- **Источник:** `docs/gameDocs/featureBacklog.md` #… / запрос …
- **Связанные правила:** `docs/gameDocs/rules.md §…` (или «нет/не применимо»)
- **Владелец спеки:** analyst

## Цель и ценность
…

## Бизнес-поведение и сценарии
…

## Scope / Non-scope
- **In scope:** …
- **Out of scope:** …

## Разрешённые неоднозначности и решения
- (вопрос → решение → основание/ссылка; если требует правки `rules.md` — эскалация, статус blocked)

## Критерии готовности к декомпозиции / приёмки (бизнес)
- [ ] …

## Открытые вопросы
- Нет (обязательно для `ready_for_decomposition`) / список с владельцем и блокером

## Примечания для architect
- Ограничения, зависимости, риски, предложения по нарезке (не `T-*`).
```
